01

Check prerequisites

Use Node.js 24+, npm and an Anthropic key with access to the configured model. Keep optional dependencies enabled. This app pins TypeScript SDK 0.3.310; Python is not needed to run it.

02

Install, configure and start

From presentations use the commands below. Preserve an existing .env or copy the safe template. Enter your key locally and restart after edits. The scripts explicitly load the optional file; shell variables take precedence.

cd .\agent-sdk\lesson13-setting-sources
npm ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
npm start
# http://127.0.0.1:3113
ANTHROPIC_API_KEY=your_api_key
CLAUDE_MODEL=claude-sonnet-4-6
PORT=3113
03

Run project-only sources

Keep Project only and Alpha. Run once. Inspect the actual project instruction marker, project filesystem hook record and programmatic Read callback. The trusted command trace should show project enabled, without user/local fixture flags.

04

Compare with an empty source list

Select No filesystem sources and repeat the same task. Inspect [] in the actual options, no returned fixture rule markers, no filesystem hook record and an actual programmatic callback. The model is still allowed to Read data.md; [] does not erase the whole machine’s configuration.

05

Select user plus project

Run User + project. Observe both corresponding instruction markers and environment flags. Local is not selected. Compare the actual response, filesystem trace and callback evidence rather than replacing them with an expected answer.

06

Omit the option explicitly

Run Omit settingSources. The property is genuinely absent in the object, rather than passed as []. With the pinned runtime the user, project and local fixtures load. Observe the local instruction marker and local trace flag in addition to the other layers.

07

Compare two private classroom directories

Choose Private classroom directory configuration, run Alpha, then Beta. Each has distinct owned cwd/home/config paths, [], disabled auto memory and strict MCP config. Confirm the workspace marker from each actual data read. These shared-machine directories do not establish production isolation.

08

Inspect files, use the terminal and troubleshoot

Use the fixture selector to read the safe host view; it is not supplied to the agent prompt. Run CLI and web experiments sequentially. Configure the actual Git Bash path on Windows if requested. Keep the server terminal open and use Ctrl+C to stop it. A second start recognizes this app; choose another PORT for an unrelated listener. Unexpected markers or hook failures remain actual outcomes to investigate.
